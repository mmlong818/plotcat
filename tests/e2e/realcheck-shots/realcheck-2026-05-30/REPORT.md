## ✅ 已即时修复

### 1. 关系类型切换洗掉自定义名称（P0 bug）
**问题**：自定义名「强制婚约」在切到"对抗→强力对手" chip 后被覆盖丢失。
**修复**：拆字段——`relationship_kind` 存类型槽（chip 值），`relationship_type` 存显示名（自定义）。chip 切换只影响 kind，不动用户填的自定义名。

### 2. 结构骨架"故事核心"默认折叠（P0）
**问题**：showrunner 第一件要写的 logline / theme / 核心冲突藏在折叠条后。
**修复**：`<details>` 默认 `open`；空状态提示从"点击展开填写"改为"先写一句话：这部剧凭什么留住观众"。

### 3. 节拍命名不专业（P1 #5）
**问题**：开场印象 / 压力波 / 压力推进 — 不是行业术语。
**修复**：改用 Save the Cat 通译——
- 开场印象 → **开场画面**（opening image）
- 基础铺陈 → 铺陈
- 诱发事件 → **触发事件**（catalyst）
- 娱乐段落 → **承诺段落**（fun and games / promise of premise）
- 中点翻转 → 中点反转
- 压力上升 → **反派逼近**（bad guys close in）
- 至暗时刻 → **灵魂黑夜**（dark night of the soul）
- 危机时刻 → **危机抉择**（crisis）
- 压力波 → **余震段**（aftershock）
- 终局行动 → 终局对决
- 结尾印象 → 结尾画面（final image）

### 4. "已成稿"绿标判定升级（P1 #9）
**问题**：18576 字 24 场全打"已成稿"绿标，但有重复对白和八股描述。
**修复**：加 `sceneScriptQualityCheck`：
- < 50 字 → 未撰写
- < 200 字 → 草稿
- 缺场景头 INT./EXT. → **待审**（黄色 review 状态 + tooltip 列出原因）
- 对白行 < 2 → **待审**
- 通过全部检查 → 已成稿

## 🚨 待决策（颠覆性大问题）

### 大问题 1：AI 跨场台词重复 / 角色串台词
**李季原话**：
> 「点开一读全是 AI 八股；"我守了三百年，今天你却要我交还" 出现在 #1 和 #2；#1 阿芜的台词跟玄昭一模一样——AI 抄了上一句填下一句。**我会立刻放弃用 AI 批量生成全部。**」

**当前状态**：已在 prompt 加注入"上一场剧本末尾摘录 + 已用过开场首段指纹 + 反同质化硬约束"4 条。但**李季看的剧本是修复前生成的存量内容**——新生成会显著改善，但需要清空旧脚本重写才能完全验证。

**需用户决策**：
- 方案 A：**保守** — 仅对新生成的场景生效（现状）。旧剧本 18576 字保留，用户自行决定哪些场要重写。
- 方案 B：**激进** — 加按钮「全片重写（依次清空 + AI 写本场）」一键清空所有 script_full 重新批量生成。耗 token 大但能彻底刷新。
- 方案 C：**最严** — 服务端加台词相似度检测，AI 输出后做后处理：检测对白行 Levenshtein 相似度 > 0.7 → 自动二次请求要求改写。需要改 server。

### 大问题 2：场景拆解 ≠ 拆解
**李季原话**：
> 「切换两场场景，右侧字段几乎一模一样。我没真"拆解"，只是给场景挂了个标签。**我会绕开这页直接去写剧本。**」

**需用户决策**：
- 方案 A：**强制必填** — 进入剧本撰写前，每场必须填"进场状态 → 出场状态"差值，否则 AI 写本场 disabled。
- 方案 B：**质检 hook** — 场景列表上「进场=出场」的场标红警告（不阻断），用户自决。
- 方案 C：**AI 辅助拆解** — 新增「AI 拆这场」按钮：基于剧情卡的 purpose/conflict/change 自动填写场景的 entry_state/exit_state/obstacle/beat_summary。

### 大问题 3：致命缺失「戏剧性判断」
**李季原话**：
> 「工程上很完整，但**没有任何一处问我**：这场戏的冲突主张是什么？这场出场和进场的人物状态差是什么？这段对白的潜台词是什么？主角的弧光在这一场推进了几度？没有这些，工具就是个漂亮的填空表+AI 八股生成器。我填完字段、按了 AI 批量生成、得到 18576 字"已成稿"——但**没有一场戏是能拍的**。它在帮我"完成项目"，而不是"写好戏"。」

**需用户决策**：
- 方案 A：**仅加诊断面板** — 全片诊断页，扫描所有场景报告：缺冲突主张 / 无状态差 / 无潜台词 / 弧光停滞 → 列清单。用户自决要不要处理。
- 方案 B：**写本场前强校验** — 写本场 AI 按钮 disabled until 该场填齐 4 项（冲突主张 / 状态差 / 潜台词目标 / 弧光位置）。强制深度思考。
- 方案 C：**编辑器加 4 字段** — 在场景编辑器加 4 个新字段（冲突主张 / 状态差 / 潜台词 / 弧光），AI 写本场时强制使用，能写出真正有戏的本子。**最重要也最大改动**。

### 大问题 4（次要 P1）：人物"性格特质" tag 化扁平人物
**李季原话**：「选 tag 不会让人物立体，只会让人物扁平化。MBTI/马斯洛是噱头。」
**待决策**：是否新增「主导防御机制 / 创伤来源 / 矛盾欲望」三个长 textarea 替代 tag？

### 大问题 5（次要 P1）：剧情卡编辑抽屉遮住矩阵
