# 评审 B：项目中心 + 创建向导 + 结构骨架 + 人物核心

| 页面 | 评分 |
|------|------|
| 项目中心 | 4/10 |
| 新建向导 | 3/10 (P0 灾难) |
| 结构骨架 | 5/10 |
| 人物核心 | 5/10 |

## P0（必修）

- **新建项目 Modal 仅 ~280px 宽**，三选项被压缩成竖排小卡，文字截断；无遮罩或遮罩过浅。改 720px、横排 220×220 卡片、`backdrop rgba(20,15,8,0.55) + blur(8px)`、右上角 × 按钮。
- **背景 #E8DBC4 + 卡片 #F5EBDC** 对比度 <1.2，卡片"溶"在背景里。背景 → `#FAF6EE`，卡片纯白 + 1px 边 + shadow-sm。
- **结构骨架顶栏 11 个元素挤一行**（stepper + 主 CTA + 状态 chip + 保存 + 项目中心 + 资料库 + ⚙ + 🌙）。Stepper 独占一行居中；主 CTA 移到内容区右上而非全局 nav。
- **人物核心性格 chip 灰色对比度 <2:1 违反 WCAG AA**。chip 描边 `#B89968` + 文字 `#6B5638`；选中态实色填充。

## P1（应修）

- 项目中心每张卡片右上角"继续创作"橙色胶囊重复 → 视觉噪音爆炸。默认隐藏，hover 浮现或改 ghost。
- "最近编辑/种草试验田" 区段标题与卡片网格无视觉分隔。区段标题 18/600 + 上方 32px margin + 计数 chip。
- 结构骨架三幕色带（橙/蓝灰/绿）饱和度太低，"第二幕"几乎看不出色差。改 `#FFF1E0 / #EEF4FA / #ECF5EE` + 左侧色条 4px。
- 结构骨架节拍卡标题在 tag 区重复了一遍 → 顶部小 tag 改为"节拍 1·0–10%"等元信息。
- 待填卡片虚线对比 <1.5 几乎看不见。虚线改 `#C9A876 1.5px` + `+` 图标。
- 顶部"故事核心"56px 通栏纯属浪费 → accordion 默认折叠为 36px chip。
- 人物核心 input 全用米黄填色无边框，像 readonly。白底 + 1px `#D4C2A0` 边 + focus ring-2。
- 人物核心主标题旁应该用 role chip，删除冗余的"故事角色"select 字段。
- 人物核心 section 标题（动机与秘密/弧光变化）橙色 12px 比正文 label 还小。改 16/600 + 上方 24px margin + 下方 1px divider。
- 人物核心 MBTI/马斯洛折叠区藏在一个空 input 里看不出可展开 → 改明显 accordion row + chevron。

## P2（抛光）

- 圆角不统一（按钮 16、卡片 8）→ 统一 10px。
- "✓已同步"绿 chip + "本地服务"灰 chip + "保存"橙按钮三种风格并列 → 统一 chip 体系。
- "删除"危险按钮和普通按钮一样 → ghost danger，hover 变红。

## 一致性问题

- 全局米黄系导致对比度不足、层级塌陷
- 橙色 accent 在 CTA/chip/section header/状态指示同时使用 → 失去强调价值
- 表单缺边框使输入看起来像 disabled
- 缺少完整 token 体系 + 字号阶梯
