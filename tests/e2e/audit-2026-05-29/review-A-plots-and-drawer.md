# 评审 A：剧情开发 + 卡片编辑抽屉

**评分：3.5 / 10**

## P0 — 阻断使用 / 视觉灾难

1. **米黄底色 + 大量橙色按钮** → 像"中医诊所/竹简"，与"世界级工具"定位相悖。背景改 `#FAFAF9` (off-white) 或深色；橙色仅保留 1 个主 CTA，其余 ghost。
2. **顶部工具栏 9 个按钮等权扁平** → 当前页激活态识别困难。拆三组：左侧 tab（仅文字 + 2px indicator）、中间留白、右侧操作（保存 ghost + 主 CTA filled）；按钮 36 → 28px 高。
3. **抽屉与画布无视觉分隔** → 共用米黄底，1px 边框；无遮罩。抽屉背景升一档 `#FFFFFF`，画布盖 `rgba(0,0,0,.32)` + blur 4px；抽屉左缘 24px 软阴影。

## P1 — 结构性

4. **剧情卡密度过高** → 140px 宽塞 3 行，标题/正文字号差 < 2px。最小宽 200px、padding 12、标题 14/600、正文 12/400/60%、间距 16px、chip 移到底部独立行。
5. **幕/场次分隔无层级语义** → 字号几乎相同。幕 16/600、场次 12/500/uppercase；"未归类"区 `#F3F4F6` 槽 + 32px 留白。
6. **抽屉表单密度灾难** → 字段间距 < 8px、30+ chip 堆一坨。字段节奏 20px；label `12/500 #6B7280` + 6px gap；chip 按"情感/场景/类型"分组，每组 ≤ 8 个超出折叠。
7. **左侧时间轴退化为小点** → 无标签/数字/hover。每点配 "场N" 标签 + 当前场次橙色高亮 + hover tooltip。

## P2 — 抛光

8. 字体改 `Inter / 思源黑体 Medium`。
9. 圆角不统一（按钮 6、卡片 4、输入 2）→ 统一 8px。
10. 标题《九重渊》改衬线 24/600 + breadcrumb 副标题。
11. chip 选中态 filled #111 文字白。
12. 原生 checkbox → 自绘 16px 圆角方块 + check icon。

## 差距诊断

> 距离 Linear 级别还差：设计令牌系统、克制色彩（90% 中性灰 + 1 品牌色）、清晰字号阶梯（12/14/16/24 四档）、8px 间距网格、模态焦点管理、"每个元素都问需要吗"的删减能力。现在的设计是在加，Linear 是在减——这是质变分水岭。
