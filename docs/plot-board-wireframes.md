# 剧情板线框说明

## 1. 总体思路

剧情板不是一张自由白板，而是两种视图共用一份数据：

- 结构视图
- 排演视图

两者都围绕同一个对象：

- 幕
- 节点
- 轨道
- 剧情卡

## 2. 顶部公共区

所有剧情板视图共用一个紧凑顶部。

```text
┌ 项目名 ─ 保存 ─ 视图切换(结构 / 排演) ─ 过滤器 ─ 新增剧情卡 ┐
└ 当前幕数 / 当前主线 / 当前方案组 / 未定义卡数量 / 待锁定数量 ┘
```

说明：

- 第一行是操作层
- 第二行是状态层
- 不再放大段说明文案

## 3. 结构视图线框

结构视图强调“幕 -> 节点 -> 轨道内容分布”。

```text
┌──────────────────── 剧情板：结构视图 ────────────────────┐
│ 顶部工具栏                                                 │
├───────────────┬──────────────────────────────┬────────────┤
│ 左侧：结构概览 │ 中间：按幕展开的剧情区         │ 右侧：当前卡详情 │
│                │                              │            │
│ 幕统计          │ [第一幕色块] [第二幕色块] ...  │ 标题       │
│ 节点覆盖        │  ├ 开场节点                  │ 轨道归属     │
│ 缺口提醒        │  │  主线行：卡 卡 卡         │ 前后依赖     │
│                │  │  支线行：卡 卡           │ 关联角色     │
│                │  │  未定义行：卡            │ 影响锁定层   │
│                │  ├ 触发事件节点              │ 场景投影     │
│                │  │  主线行：卡 卡           │            │
│                │  │  方案行：卡 卡           │            │
├───────────────┴──────────────────────────────┴────────────┤
│ 底部：节点缺失 / 节奏薄弱 / 主线断裂提示                        │
└───────────────────────────────────────────────────────────┘
```

### 结构视图颜色归属

- 幕：大底色块
- 节点：幕内浅块
- 轨道：只做标签和细分隔
- 卡片：中性

## 4. 排演视图线框

排演视图强调“轨道 -> 排序 -> 方案比较”。

```text
┌──────────────────── 剧情板：排演视图 ────────────────────┐
│ 顶部工具栏                                                 │
├───────────────────────────────────────────────────────────┤
│ 幕分隔条：第一幕 │ 第二幕 │ 第三幕 │ 第四幕 │ 第五幕         │
├───────────────────────────────────────────────────────────┤
│ 正式主线轨  [卡][卡][卡]   [卡][卡]      [卡][卡][卡]       │
├───────────────────────────────────────────────────────────┤
│ 支线 A      [卡][卡]       [卡]          [卡][卡]           │
├───────────────────────────────────────────────────────────┤
│ 支线 B      [卡]           [卡][卡]      [卡]               │
├───────────────────────────────────────────────────────────┤
│ 未定义      [卡][卡][卡]                                     │
├───────────────────────────────────────────────────────────┤
│ 方案轨 A    [卡][卡]       [卡][卡]                         │
├───────────────────────────────────────────────────────────┤
│ 方案轨 B    [卡]           [卡][卡][卡]                     │
├───────────────────────────────────────────────────────────┤
│ 方案轨 C    [卡][卡]                                         │
└───────────────────────────────────────────────────────────┘
```

### 排演视图颜色归属

- 轨道：大底色块
- 幕：顶部栏和轻分隔
- 卡片：中性

### 排演视图允许的动作

- 卡片在同轨道内拖动排序
- 卡片跨轨道移动
- 卡片拖入未定义区
- 复制一张卡到方案轨
- 从方案轨提升为正式版本

## 5. 卡片结构线框

剧情卡不建议做重颜色底，而建议做中性卡 + 局部标记。

```text
┌─────────────────────────────┐
│ 左侧标记条  标题             │
│ 轨道标签   层级标签   状态标签 │
│ 摘要一句话                    │
│ 角色标签  方案标签  节点标签   │
└─────────────────────────────┘
```

### 卡片上的颜色分工

- 左侧标记条：对象归属或当前选中
- 轨道标签：轨道色
- 角色标签：角色色
- 状态标签：锁定 / 风险 / 待确认
- 卡片底：中性

## 6. 角色色在剧情板里的落点

角色色不应该让整张剧情卡变色，只用于这些地方：

```text
剧情卡底部的人物标签：
[主角] [对手] [盟友]
```

或者：

```text
剧情卡右上角的小色点：
● 主角   ● 对手
```

## 7. 方案比较区

当用户点中某个方案组时，右侧详情区应切成方案比较模式。

```text
┌ 方案比较 ───────────────────┐
│ 问题：主角最后是否公开真相      │
├─────────────────────────────┤
│ 方案 A：公开                  │
│ 影响：主线收束更强，代价更大     │
├─────────────────────────────┤
│ 方案 B：隐瞒                  │
│ 影响：人物更复杂，季尾钩子更强   │
├─────────────────────────────┤
│ 方案 C：部分公开              │
│ 影响：折中，但主题更弱         │
└─────────────────────────────┘
```

## 8. 与锁定层的关系

剧情板和锁定层之间，建议加一个“正式版本筛选器”。

```text
剧情板
  ↓
只保留正式主线 + 已采纳支线
  ↓
进入锁定层
  ↓
投影到角色 / 关系 / 时间线 / 伏笔 / 场景
```

## 9. 与场景页的关系

场景页不要直接继承方案轨内容。

推荐关系：

```text
正式主线卡
已采纳支线卡
        ↓
   场景拆分池
        ↓
     场景页
```

## 10. 线框优先级

第一版先做：

1. 结构视图
2. 排演视图
3. 中性卡片 + 区域色块
4. 方案轨
5. 正式版本筛选

第一版暂不做：

- 无限画布
- 任意位置摆放
- 导演分镜式界面
- 镜头级卡片
