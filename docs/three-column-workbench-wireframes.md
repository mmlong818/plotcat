```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 顶部总工具栏（可展开 / 压缩 / 隐藏）                                        │

│ 左列：步骤栏 │ 中列：主编辑区                               │ 右列：速查与工具 │
│ 结构页       │ 当前步骤唯一主对象                           │ 当前上下文变化    │
```

## 10. 右列统一骨架

```text
┌────────────────────────┐
│ 当前对象卡              │
├────────────────────────┤
│ 关联对象速查            │
├────────────────────────┤
│ 风险与检查              │
├────────────────────────┤
│ AI 工具                 │
├────────────────────────┤
│ 跳转与引用              │
└────────────────────────┘
```

这样做的目的不是“每页长得一样”，而是让用户快速理解右列永远是：

- 我现在在编辑谁
- 它牵动了谁
- 我现在能做什么
